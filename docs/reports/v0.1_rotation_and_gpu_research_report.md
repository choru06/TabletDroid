## 2. 🔄 Windows 물리 센서 ↔ RotationBridge 자동 연동 구현

1. **`WindowsDisplayOrientationWatcher` (`WindowsSensors.cs`)**:
   * `Microsoft.Win32.SystemEvents.DisplaySettingsChanged` 이벤트 구독.
   * Win32 `GetSystemMetrics(SM_CXSCREEN/SM_CYSCREEN)`를 통해 디스플레이 종횡비(가로 1920×1200 ↔ 세로 1200×1920) 실시간 감지.
   * 300ms 디바운스(`DebouncedOrientationWatcher`)를 거쳐 떨림 방지 후 `OrientationChanged` 통지.

2. **`RotationBridge` (`RotationBridge.cs`)**:
   * 호스트 물리 회전 이벤트 수신 시 `accelerometer_rotation 0` 및 `user_rotation <0|1|2|3>`을 에뮬레이터에 직접 주입.
   * 가로 ↔ 세로 회전 시 게스트 안드로이드가 즉시 동기화되도록 연동.

3. **테스트 및 검증**:
   * 단위 테스트 13건 전체 통과 (`13 Passed, 0 Failed`).
   * `TabletDroid.Host` WPF 전체 솔루션 0 Warning, 0 Error 빌드 통과.
