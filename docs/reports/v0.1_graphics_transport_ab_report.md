## 1. Executive Summary & Context

Prior performance explorations hypothesized that the default guest-to-host IPC transport (`pipe` / Goldfish Pipe) was the primary throughput bottleneck for 60 FPS presentation, and suggested tuning Address Space Graphics (ASG) ring buffer parameters.

To empirically evaluate this hypothesis, we conducted a **strict cold-boot A/B/C/D characterization** comparing:
1. `hw.gltransport = pipe` (Initial Goldfish Pipe baseline)
2. `hw.gltransport = asg` (Address Space Graphics shared-memory transport)
3. `hw.gltransport = virtio-gpu` (VirtIO GPU virtqueue transport)
4. `hw.gltransport = pipe` (Re-test for thermal and temporal drift verification)

All tests were executed under the canonical deterministic probe (`com.tabletdroid.benchmark`, 1920×1200 @ 280dpi, 800 px/s, 10s warmup, 30s measurement) with **Telemetry OFF** and evaluated against all **8 Fail-Closed Validity Gates**.

## 4. [INFERENCE] Core Findings & Comparative Analysis

1. **`pipe` is the Superior Graphics Transport**:
   - `pipe` achieved **56.75 FPS** (initial) and **59.93 FPS** (re-test), delivering near full 60 FPS presentation rate with P50 frame latencies of **17.79 ~ 32.58 ms**.
2. **`asg` Severe Performance Penalty**:
   - `asg` resulted in a **-20.16 FPS regression** (36.59 FPS vs 56.75 FPS) and more than doubled P50 latency (68.30 ms vs 32.58 ms).
3. **`virtio-gpu` Performance**:
   - `virtio-gpu` performed respectably at **53.25 FPS**, but remained slightly behind `pipe` with higher latency variance (StdDev: 6.10 vs 0.42~3.27).
4. **Drift Verification**:
   - `pipe (initial)` (56.75 FPS) vs `pipe (retest)` (59.93 FPS) confirms that the host system maintained consistent thermal and computational characteristics throughout the 15-minute test run.

---

## 5. [DECISION] Architectural Decisions

1. **Standard Transport Protocol**:
   - `hw.gltransport = pipe` is confirmed and locked as the standard transport configuration for TabletDroid.
2. **ASG Ring Buffer Tuning Dismissal**:
   - Because default `asg` is significantly slower than `pipe` across all 5 trials under strictly deterministic conditions, **ASG ring-size tuning is dismissed** as an optimization direction.
3. **Next Phase Optimization Focus**:
   - Since the guest transport layer delivers up to 59.93 FPS under `pipe`, the residual rendering engineering should focus on **Host Viewport Embedding & DirectX/DXGI presentation overhead**.
