## 2. 파일별 수정 및 추가 내역 (Commit `115fea1`)

### 1) `launch.bat` (신규)
* **목적**: 사용자가 IDE 터미널 또는 탐색기에서 1클릭으로 대화형 GUI 에뮬레이터와 TabletDroid Host를 실행할 수 있는 대화형 런처.
* **내용**: 시스템 전역 환경 변수를 오염시키지 않고, 배치 프로세스 내부 격리 환경에서 `JAVA_HOME`, `ANDROID_HOME`, `DOTNET_ROOT`, `PATH`를 바인딩하여 안전하게 실행.

### 2) `scripts/windows/create-avd.ps1` (수정)
* **목적**: Flow Z13 1920x1200 태블릿에 최적화된 고성능 AVD 생성.
* **내용**:
  * 비표준 `--device tablet` 인자 제거 및 무인 자동 생성(`echo no`) 파이프라인 구축.
  * `config.ini` 고성능 하드웨어 속성 강제 적용:
    * `hw.gpu.enabled = yes` & `hw.gpu.mode = host` (RTX 3050 Ti 직접 렌더링)
    * `hw.cpu.ncore = 8` (8코어 집중 할당)
    * `hw.ramSize = 6144` (6GB RAM)
    * `vm.heapSize = 512M` (GC 프리징 제거)

### 3) `scripts/windows/run-spike.ps1` (수정)
* **목적**: 실기 환경 원클릭 자동 검증 러너.
* **내용**:
  * `emulator.exe -accel-check`를 통한 권한 오류 없는 WHPX 감지 로직 적용.
  * 고속 DNS 서버(`8.8.8.8, 1.1.1.1`) 인수 추가로 Play Store 다운로드 지연 해결.
  * 도구 경로 사전 자동 해결 및 요약 리포트 출력.

### 4) `scripts/windows/clean-user-env.ps1` (신규)
* **목적**: 전역 사용자 환경 변수 오염 복구용 스크립트.
* **내용**: 사용자 레지스트리(`HKCU\Environment`)에서 `DOTNET_ROOT` 및 로컬 경로를 제거하여 시스템 기본 `.NET Framework`와 `.NET 8/10` 런타임 무결성 복원.

### 5) `scripts/windows/setup-env.ps1` / `scripts/windows/install-sdk-packages.ps1` (신규)
* **목적**: Flow Z13 신규 환경에서 .NET 9 SDK, OpenJDK 17, Android cmdline-tools, platform-tools, emulator, Android 34 Play Store 이미지를 완전 자동 다운로드/설치/라이선스 승인하는 환경 구축 스크립트.

### 6) `scripts/windows/get-device-info.ps1` / `scripts/windows/test-tools.ps1` (신규)
* **목적**: 안드로이드 OS 버전, 모델명, 해상도, DPI, 포트 포워딩 상태를 즉시 점검하는 진단 도구.

## 3. 핵심 기술 분석 및 성능 병목 원인

### 1) WHPX vs AEHD 하이퍼바이저 충돌 이슈
* **발견**: Windows 11의 가상화 기반 보안(VBS)이 활성화된 환경에서 서드파티 커널 드라이버(`aehd.sys`)가 VT-x를 직접 점유하려 할 경우 하드웨어 데드락(프리징)이 발생함.
* **해결**: Windows 네이티브 하이퍼바이저인 **WHPX(Windows Hypervisor Platform)**로 완전히 전환하여 안정적인 하드웨어 가속 확보.

### 2) 순정 QEMU의 20fps 렌더링 병목 분석
* **IPC 파이프 복사 오버헤드**: Google 순정 QEMU는 프레임버퍼를 IPC 파이프(`hw.gltransport = pipe`)로 CPU 메모리를 거쳐 복사하므로, 고해상도(1920x1200)에서 대역폭 병목 및 20~30fps 수준의 프레임 드롭 발생.
* **GMS 백그라운드 부하**: Play Store 초기 구동 시 Play Protect 보안 스캔 및 클라우드 인덱싱으로 인한 I/O 점유.
* **JIT 컴파일**: Instagram 초기 설치 시 AOT 컴파일 미적용으로 인한 인터프리터 실행 지연.
* **해결 방안 (v0.1)**: **DXGI Direct3D11 Shared Texture (Zero-Copy)** 기반 GPU 서피스 직결 렌더러 구현 및 `dex2oat speed` 사전 컴파일 적용.

## 4. v0.1 로드맵 및 차기 작업 계획

1. **DXGI / D3D11 Shared Handle Zero-Copy 렌더러 임베딩 (20fps → 60/120fps)**
   * QEMU 기본 창 프레임을 떼어내고, TabletDroid Host 창에 GPU 공유 핸들로 직접 렌더링.
2. **ART Ahead-Of-Time 풀속도 사전 컴파일 파이프라인 (`dex2oat speed`)**
   * 인스타그램 등 설치 앱의 AOT 사전 컴파일 자동화.
3. **물리 센서 자동 회전 브리지 (`RotationBridge`) 실시간 연동**
   * Flow Z13 본체 센서 감지 시 실시간 `user_rotation` 주입.
4. **시스템 UI 클린화**
   * 불필요한 내비게이션/상태바 제거 및 태블릿 단독 뷰포트 최적화.
