## 2. 🛠️ 구현 내용: `benchmark-spike.ps1` 추가

성능 체감(~20fps)의 근본 원인을 과학적으로 규명하기 위해 **안드로이드 공식 프로파일링 도구 연동 벤치마크 스크립트**를 구축했습니다.

### 1) 자동 계측 메트릭
* **`dumpsys gfxinfo <package> framestats` 파싱**:
  * 프레임별 `IntendedVsync`부터 `FrameCompleted`까지 나노초 단위 정밀 타이밍 추출.
  * Average FPS, P50 (ms), P90 (ms), P99 (ms), Jank Rate(16.6ms 초과 비율 %) 계산.
* **Cold App Launch Time**: `am start -W -S`를 통한 밀리초 단위 시작 시간 계측.
* **Host & QEMU 리소스**: QEMU 메모리(WorkingSet MB) 및 CPU 점유율 추적.

### 2) A/B 가설 분리 테스트 매트릭스
1. **ART JIT vs AOT (`cmd package compile -m speed -f`)**:
   * JIT 컴파일러 오버헤드와 렌더링 파이프라인의 영향을 독립적으로 분리.
2. **해상도 Scaling (`1920x1200` ➔ `1600x1000` ➔ `1280x800`)**:
   * 픽셀 전송/IPC 복사 병목 vs VM 스케줄링/SurfaceFlinger Vsync 병목을 명확히 판별.

### 3) 자동 리포트 생성
* 벤치마크 완료 시 `docs/performance/baseline_v0.1.md`에 실시간 수치와 분석 결론을 자동 기록.
