## 3. [IMPLEMENTED] Frame & Jank Metric Semantic Disambiguation

1. **SurfaceFlinger Presented FPS**:
   - **Definition**: Rate of unique composited frame presentations to the host display swapchain (`deltaTotalFrames / deltaSeconds`).
   - **Meaning**: Measures real end-to-end presentation throughput on the Windows display surface.
2. **HWUI Frame Latency (`FrameCompleted - IntendedVsync`)**:
   - **Definition**: The duration between Android Choreographer intended Vsync and the GPU rendering completion of that frame by Skia/HWUI.
   - **Meaning**: P50 (17.76 ms) and P90 (18.69 ms) reflect internal rendering pipeline queue depth, which is decoupled from presentation FPS.
3. **Official SurfaceFlinger FrameTimeline Jank %**:
   - **Definition**: Directly parsed from `dumpsys SurfaceFlinger --timestats` (`jankyFrames / totalTimelineFrames`).
   - **Result**: **0.0% Jank** (0 janky frames out of 1800 frames per 30s trial) and **0 dropped frames**.
4. **Diagnostic Latency Threshold**:
   - The diagnostic metric previously labeled "Jank %" is renamed to `LatencyOver16_67Percent`.

## 4. [IMPLEMENTED] Fail-Closed Graphics Configuration Auto-Remediation

In `scripts/windows/run-spike.ps1`:
- Explicitly inspects `hw.gpu.mode` and `hw.gltransport` from `$env:USERPROFILE\.android\avd\<AvdName>.avd\config.ini`.
- If either value diverges from `host` or `pipe`, the script automatically normalizes the configuration and logs:
  `[CONFIG_REMEDIATED] Normalized AVD config to hw.gpu.mode=host, hw.gltransport=pipe.`
- Fail-fast enforcement ensures non-conforming configurations are rejected prior to launch.
